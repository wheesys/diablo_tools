## 二、存档文件格式调研

### 2.1 核心文件类型

| 文件扩展名 | 用途 | 说明 |
|-----------|------|------|
| `.d2s` | 角色存档文件 | 包含角色所有数据：属性、技能、物品、任务、传送点等 |
| `.d2i` | 共享仓库文件 | SharedStashSoftCoreV2.d2i / SharedStashHardCoreV2.d2i |
| `.ma0`~`.ma3` | 地图缓存文件 | Automap差分快照，可安全删除 |

### 2.2 D2S 存档文件结构

**基本信息**:
- **文件格式**: 二进制格式
- **字节序**: Little Endian (x86原生)
- **编码**: 部分字段使用Huffman编码压缩

**D2R版本位字段变化**:
```
str/dex/vit/ene: 10 bits
stats left: 10 bits
skill left: 8 bits
life/max, mana/max, stamina/max: 21 bits (游戏中值除以256)
level: 7 bits
exp: 32 bits
gold/stash gold: 25 bits
```

**主要数据结构**:
1. **文件头** - 魔数、版本号、校验和
2. **字符基本信息** - 名称、职业、等级、状态
3. **属性数据** - 基础属性、当前状态
4. **技能数据** - 技能等级、技能点
5. **任务数据** - 各幕任务完成状态
6. **传送点数据** - 各难度传送点状态
7. **物品列表** - 装备、背包、仓库物品
8. **雇佣兵数据** - 雇佣兵状态和装备
9. **尸体数据** - 尸体上的物品

### 2.3 物品数据格式

**物品标识**:
- `JM` (0x4d, 0x4c) - 物品开始标记
- 物品代码为32位，从bit offset 76开始，每8位一个ASCII字符

**物品数据包含**:
- 物品基础代码 (3字符代码)
- 物品品质 (普通/魔法/稀有/暗金/套装等)
- 基础属性 + 额外属性列表
- 符文/宝石/镶嵌物信息
- 制造者信息
- 个人化名字

## 五、跨平台桌面框架调研

### 5.1 框架对比 (2025年)

| 框架 | 语言 | 安装包大小 | 内存占用 | 开发语言 | 学习成本 | 推荐度 |
|------|------|-----------|---------|---------|---------|-------|
| **Tauri 2.0** | Rust | 极小 (~3MB) | 极低 | Rust + Web前端 | 高 | ⭐⭐⭐⭐⭐ |
| **Electron** | C++/Node | 大 (~100MB+) | 高 | JavaScript | 低 | ⭐⭐ |
| **Flutter** | Dart | 中 (~40MB) | 中 | Dart | 中 | ⭐⭐⭐⭐ |

### 5.2 Tauri 2.0 推荐方案

**优势**:
1. **体积小**: 相比Electron缩小97%体积
2. **性能高**: Rust后端，原生性能
3. **安全性强**: 权限系统精细控制
4. **跨平台**: Windows/macOS/Linux/Android/iOS
5. **现代架构**: 前后端分离，前端可选用任意Web框架

**技术栈建议**:
- **后端**: Rust (处理二进制文件解析)
- **前端**: React/Vue/Svelte (任选)
- **UI组件**: 现代组件库

**为什么选择Rust**:
- 存档文件是二进制格式，需要位级操作 (BitReader/BitWriter)
- Rust在处理二进制数据方面安全高效
- 零成本抽象，性能优秀

### 5.3 替代方案

**如果团队不熟悉Rust**:
- **Go + Wails**: Go语言跨平台框架
- **C# + Avalonia/UI**: .NET跨平台方案
- **Electron + Node.js**: 生态最成熟，但体积大

## 六、技术架构建议

### 6.1 分层架构

```
┌─────────────────────────────────────────┐
│           前端 UI (Tauri WebView)        │
│  - React/Vue 组件                        │
│  - 表单验证、用户交互                    │
└─────────────────────────────────────────┘
                    ↑ Tauri IPC
┌─────────────────────────────────────────┐
│         后端 API (Rust)                  │
│  - 文件读写接口                          │
│  - 数据验证                              │
└─────────────────────────────────────────┘
                    ↑
┌─────────────────────────────────────────┐
│       核心解析库 (Rust)                  │
│  - D2S Parser / Writer                  │
│  - D2I Parser / Writer                  │
│  - Item Parser / Writer                 │
└─────────────────────────────────────────┘
                    ↑
┌─────────────────────────────────────────┐
│       位级I/O层 (Rust)                   │
│  - BitReader / BitWriter                │
│  - Huffman编解码                        │
└─────────────────────────────────────────┘
```

### 6.2 数据流

1. **读取存档**: File → BitReader → Parser → Structs → IPC → UI
2. **保存修改**: UI → IPC → Structs → Writer → BitWriter → File
